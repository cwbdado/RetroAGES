# RetroAGES

[English](README.md) · [Português (Brasil)](README.pt-BR.md)

**RetroAGES** é um emulador independente de **Sega Master System** e **Mega Drive / Genesis**. Este repositório é dedicado ao emulador e às suas versões; o código-fonte não é distribuído aqui.

[**Jogue no navegador ou baixe para Windows no itch.io**](https://cwbdado.itch.io/retroages) · [**Versões no GitHub**](https://github.com/cwbdado/RetroAGES/releases) · [Ko-fi](https://ko-fi.com/cwbdado)

## Sistemas e versões

- **RetroAGES 0.3.0 — Windows x64:** emula Master System e Mega Drive / Genesis.
- **RetroAGES 0.2.2-alpha.3:** versão anterior focada em Master System.
- **Versão para navegador:** disponível no itch.io.

As versões anteriores continuam disponíveis. As páginas de download trazem informações específicas de cada versão e conteúdos opcionais.

## Recursos

- Biblioteca de jogos com fichas editáveis, capas, capturas de tela e favoritos.
- Controles configuráveis para dois jogadores e predefinições para gamepads.
- Interface em português e inglês.
- Estados salvos, com atalhos para salvar e carregar rapidamente (**F5** e **F8** no Windows).

## Como começar

1. Baixe o instalador para Windows na página de [versões do GitHub](https://github.com/cwbdado/RetroAGES/releases) ou abra a versão para navegador no [itch.io](https://cwbdado.itch.io/retroages).
2. No Windows, abra um arquivo de jogo compatível ou selecione uma pasta de cartuchos na biblioteca.
3. Configure os controles e comece a jogar.

O RetroAGES não inclui jogos comerciais nem arquivos de BIOS. Use cópias de jogos que você tenha direito de utilizar.
